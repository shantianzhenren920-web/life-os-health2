LIFE OS PWA v2.4

1. ZIPを展開して中の全ファイル・iconsフォルダをGitHub PagesなどのHTTPSホスティングに配置します。
2. Android Chromeで公開URLを開き、メニュー「ホーム画面に追加」または「アプリをインストール」を選びます。
3. データはブラウザの保存領域に保存されます。旧HTMLと公開サイトは保存領域が異なるため、旧版でJSONをエクスポートしてから新アプリでインポートしてください。
4. 写真入りデータは容量制限に注意し、JSONバックアップを定期的に作成してください。
5. HTMLをfile://で開くだけではPWAとしてインストールできません。HTTPSが必要です。
